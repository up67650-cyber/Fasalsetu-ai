🌱 FasalSetu AI

Empowering Farmers with AI-Driven Insights

FasalSetu AI is an AI-powered smart agriculture platform that helps farmers make informed decisions through crop health insights, weather intelligence, and personalized farming guidance.

🚀 Key Features

- 🌿 AI Crop Doctor – Crop disease diagnosis workflow.
- 🌦️ Weather Intelligence – Weather insights for smarter farming.
- 🌾 Smart Crop Advisory – Practical farming recommendations.
- 🤖 AI Farming Assistant – Hindi and English conversational support.
- 📊 Farmer Dashboard – Essential farming information in one place.

🛠️ Tech Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Python, FastAPI
- Database: SQLite
- AI: Gemini API (planned integration)
- Weather API: Open-Meteo
- Deployment: Render

🌐 Live Demo

https://fasalsetu-ai-frontend.onrender.com

🎯 Vision

To bridge the gap between farmers and technology by making intelligent farming support simple, accessible, and practical.
