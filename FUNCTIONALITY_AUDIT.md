## Remaining limitations and external dependencies

- **Crop disease diagnosis:** inference and response handling are implemented, but a model is not installed. Candidate community weights were not downloaded due missing class mappings/reproducibility or unclear terms. The optional training path uses the 38 PlantVillage classes; confidence is not calibrated field accuracy.
- **Dataset/model licensing:** the authors' PlantVillage Hugging Face dataset page declares CC BY-SA 3.0. Preserve attribution and review share-alike implications. The Keras repository code is Apache-2.0, but that does not verify the separate ImageNet checkpoint/data terms; no weights were downloaded. See `README.md` for sources and the explicit training workflow.
- **Treatment guidance:** the new knowledge base provides cautious symptom context and non-chemical next steps only. It does not prescribe pesticide products or dosage; local KVK/extension confirmation is required.
- **Generative AI:** no API key is configured in this environment. Provider integration is implemented but real provider generation needs backend environment variables; the available fallback is curated guidance and is labeled as such.
- **Hindi interface:** major navigation, weather, Crop Doctor, advisory and farm-form copy is translated, but some labels and stored history strings remain in English.
- **Weather/geocoding:** both depend on external Open-Meteo endpoints and internet access. Intermittent upstream TLS timeouts were observed and produce an explicit 503. The selected forecast location persists in SQLite; the separate farm-profile location is not automatically synchronized.
- **Weather risk rules:** thresholds are informational and not a replacement for IMD alerts, field inspection or agricultural extension advice.
- **Dashboard field chart:** activity counts are derived from saved SQLite records and are not sensor measurements.
- **Persistence/account scope:** SQLite stores one local farm profile; there is no login, multi-farmer isolation or cloud synchronization.
- **Build size:** production build succeeds, but code splitting may be considered later to address Vite’s chunk-size advisory.
